# Simple-Hangman-Game
Theis is a simple Hnagman game written in python,uses engi1020 and Matplotlib library 
The engoi1020 allows user to run python codes to run on Arduino Uno and use function to call input and output sensors
This games gives user 6 chances to correctly guess a word which is chosen randomnly from a lislt of list which is arranged based on difficulty level
After 6 invalid tries or correctly guessing the letters in the word, the game ends and user is given an option to continue game
This game can be played by multiple users and at the end of the game the name and scores are displayed using Matploltlib library
